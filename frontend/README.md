# Frontend

React frontend for the multi-tenant document chatbot.

## Setup

This frontend will be created using Vite + React + TypeScript.

```bash
cd frontend
npm install
npm run dev
```

## Development

The frontend runs on http://localhost:5173 during development.

## Tech Stack

- React 18
- TypeScript
- Vite
- TailwindCSS (optional)

## Note

Run the following to initialize the React project:

```bash
npm create vite@latest . -- --template react-ts
```
